# Supplementary Figure 5 — Calmodulin (CALM_BOVIN)

Extended vs collapsed states of calmodulin: **1CLL** (apo, extended) vs **1CDL** (peptide-
bound, collapsed), scored by TM-score to each reference (x = `1cll_tmscore`, y = `1cdl_tmscore`).

**Method (divide-and-conquer → per-state top-3% → occurrence voting).** Divide-and-conquer
spreads the MSA across the two states; for each state the lowest-3% (best-TM) sequences are
voted and the top-16 re-predicted (5 models × 8 seeds = 40 structures), against a 16-random
control sampled broadly from the MSA.

**Figure** = `four_panel_tmscore_1cll_1cdl.png`, generated by
`results_updated/CALM_BOVIN/run1/occurrence_voting_1cdl/top_3pct_for_1cll_1cdl/replot_four_panel.py`.
